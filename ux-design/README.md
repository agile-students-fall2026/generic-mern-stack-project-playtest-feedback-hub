# UX design assets

See [UX-DESIGN.md](../UX-DESIGN.md) for the prototype link, each screen description and verification gaps.

- `app-map.jam`: original FigJam source export.
- `app-map.png`: content-cropped App Map export.
- `prototype/playtest-feedback-hub.fig`: original Figma design file, including prototype connections.
- `wireframes/`: 17 individual 1× PNG frame/panel exports. Filenames distinguish role and state; the duplicate source title Scan QR Code is renamed to `playtester-feedback-success.png` for its success state.
- `wireframes.drawio`: unchanged starter example, not the source of the current product design.

Exports preserve the original frames. Sixteen frames are 402 × 874px, and the standalone menu panel is 286 × 874px. Loose sibling groups in the original design are preserved in the `.fig` source but are not merged into frame exports. See the instruction check in UX-DESIGN.md before final submission.
